# Explore Hatta — interactive map (prototype)

Prototype of the interactive Explore Hatta map for the web and for touch kiosks.
Wild Camel HyperMedia for Dubai Culture & Arts Authority. September 2026.

Open the site root for the website version. Add to the address:

- `?mode=kiosk&orientation=landscape` — kiosk, landscape (1920×1080)
- `?mode=kiosk&orientation=portrait` — kiosk, portrait (1080×1920)
- `&lang=ar` — Arabic (right-to-left)
- `&art=print` — the original printed artwork instead of the clean base

Opening hours, contacts and prices are placeholders ("to be confirmed"); Arabic text is a draft.
Map artwork and place copy: Explore Hatta 2026, Department of Economy and Tourism — used for this prototype only.
